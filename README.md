# Task Manager App

A simple, command-line based task manager to help individuals and small teams organize their daily tasks.

## Features
- Create, list, complete, and delete tasks.
- Persist tasks to a local file.
- Filter tasks by status.

## Stack
- TypeScript
- Node.js

## Setup
```bash
npm install
```

## Run
```bash
npm start
```

## Test
```bash
npm test
```

## Docker Commands
```bash
docker build -t task-manager-app .
docker run -it task-manager-app
```
